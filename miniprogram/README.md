# 小牛电压切换助手 · 微信小程序

原生微信小程序工程，无需安装 npm 依赖或开通云开发。页面包含车辆扫描与选择、已选设备名称、上次连接时间、电压和容量选择、20 字节命令预览及蓝牙发送。

## 导入与真机预览

1. 安装 [微信开发者工具稳定版](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，用小程序开发者微信登录。
2. 选择“导入项目”，目录选择本文件所在的 **`miniprogram/` 文件夹**。
3. 输入自己注册的小程序 **AppID**。`project.config.json` 中的 `touristappid` 仅作导入占位，真机权限及体验版验证请使用自己的 AppID；无需提供 AppSecret。
4. 选择“不使用云服务”，使用当前稳定基础库，至少 2.32.3。直接编译，无需“构建 npm”。
5. 在小程序管理后台的“用户隐私保护指引”声明“访问你的蓝牙”，用途填写“用于发现、连接车辆并发送用户选择的电池配置”。
6. 在开发者工具点击“预览”，用有权限的 iPhone 微信扫码。打开蓝牙，并允许微信的系统蓝牙权限以及小程序蓝牙授权。
7. 靠近车辆，释放 Bluefy 或其他 App 的车辆连接。点击扫描、选择车辆，等待页面显示可发送状态。
8. 选择电压和容量，核对 HEX 预览后发送，并查看车辆仪表确认。

编译器预览可检查界面，蓝牙写入结果需要 iPhone 和车辆实测。首次使用会按微信机制出现隐私、蓝牙授权提示。

## 连接通道

首次连接会实际枚举服务及特征。默认候选服务为 FFE0、FF00：

- 只有一个候选可写特征、且能确定写入方式时，自动选择。
- 多个候选，或只有其他服务时，页面要求选择命令通道。
- 写入方式不明确时，页面要求选择“无回复写”或“有回复写”。
- “连接详情与权限设置”可查看全部 UUID 和特征属性，也可切换通道和设备支持的写入方式。

真机确定正确特征后，可在 [utils/config.js](utils/config.js) 中填写 `characteristicUUID`。仍会在每次连接中重新枚举，避免直接复用旧的 iOS GATT 实例。

默认优先无回复写，与原网页一致。实际通道、写入方式和车辆响应尚需确认。一次发送 20 字节，不自动重试；写入超时提示结果未知并关闭连接。切到后台会停止扫描和释放连接，回到前台后点击“重连”或重新扫描。

## 日常自用

真机验证通过后，在开发者工具“上传”，到小程序后台“版本管理”设为体验版；给自己的微信添加相应使用权限，扫码后添加到“我的小程序”。体验版面向授权成员，公开发布需要另走后台审核流程。

本地历史存储独立于 Bluefy。清除连接记录只删除本工具的存储键。工程不请求 GitHub Pages，不需要业务域名或自建服务器；代码包下载和微信平台操作仍可能需要网络。

## 代码与测试

| 文件 | 用途 |
| --- | --- |
| `app.*`、`project.config.json` | 小程序入口和开发工具配置 |
| `pages/index/index.*` | 界面、选择器、命令预览、历史记录和权限入口 |
| `utils/ble.js` | 扫描、GATT 发现、通道选择、写入、超时和生命周期 |
| `utils/protocol.js` | 电压/容量代码和原有 20 字节协议 |
| `utils/history.js` | 上次连接名称、时间和缓存清理 |
| `utils/config.js` | 候选服务、特征 UUID 及超时时间 |
| `tests/` | 无依赖的模拟蓝牙和页面测试，打包时忽略 |

在本目录使用 Node.js 18 或更高版本运行：

```sh
npm test
```

测试不连接车辆，也不会发送真实蓝牙命令。测试覆盖 24 种组包结果、写入模式、设备切换、断线、超时、历史记录和页面绑定。车辆验收表、错误码和官方接口依据见仓库根目录的 [mini_pragram.md](../mini_pragram.md)。
